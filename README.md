# ReachOut Worldwide Donation Analytics Dashboard

![Dashboard Banner](Infographic.jpg)

## Project Overview

This project analyses donation behaviour for ReachOut Worldwide (ROW), a global non-profit organisation, using Tableau and Excel.

The objective was to identify donor trends, segment donors using RFM analysis, evaluate fundraising appeal performance, and generate data-driven recommendations to improve donor retention and fundraising outcomes.

![Dashboard](Dashboard_Screenshot.png)

## Business Problem

ReachOut Worldwide wanted to better understand donor behaviour and fundraising performance across multiple countries.

Key challenges included:

* Identifying the most valuable donor segments
* Understanding which fundraising appeals generated the highest engagement
* Tracking donation trends over time
* Improving donor retention and campaign effectiveness
* Supporting strategic fundraising decisions with data

## Tools Used

* Tableau

## Dataset Overview

* 9,494 Donors
* 39,432 Donations
* $8.68 Million Total Donation Value
* Donation Data (2019–2023)
* Multiple Donation Sources and Appeal Campaigns

## Key Analysis

### Donor Segmentation (RFM Analysis)

Applied Recency, Frequency, and Monetary (RFM) analysis to classify donors into behavioural segments:

* Loyal Donors
* New Donors
* Promising Donors
* Need Attention
* About to Lose
* Lost Donors

This enabled targeted fundraising strategies based on donor engagement and contribution patterns.

### Donation Trends and Forecasting

* Analysed donation performance from 2019–2023
* Identified seasonal and long-term donation patterns
* Forecasted future donation behaviour using historical trends
* Highlighted opportunities for fundraising growth

### Appeal Performance Analysis

* Evaluated fundraising campaign effectiveness
* Compared donation value and donor engagement across appeals
* Identified Appeal 2 as the highest-performing campaign
* Recorded a 67% donor crossover rate
* Observed a 1486% increase in shared donations

### Geographic Analysis

Analysed donation activity across countries to identify high-value donor regions.

Top contributing countries included:

* United States
* Australia
* United Kingdom

## Key Findings

* Individual donors contributed the majority of total donation revenue
* Online channels were the preferred donation source
* Loyal donors generated the highest fundraising value
* Appeal 2 achieved the strongest campaign performance
* Donor retention presents a significant opportunity for future fundraising growth

## Business Recommendations

1. Strengthen donor retention programs for high-value donor segments.
2. Increase investment in top-performing fundraising appeals.
3. Personalise communication using RFM-based donor segmentation.
4. Expand digital fundraising initiatives to align with donor preferences.
5. Prioritise fundraising efforts in high-performing geographic regions.

## Project Outcomes

* Analysed 9,494 donor records and 39,432 donation transactions.
* Evaluated over $8.68 million in donation value.
* Identified high-value donor segments through RFM analysis.
* Generated actionable fundraising recommendations.
* Developed an executive Tableau dashboard to support strategic decision-making.
